About this website

This multi-page website was constructed as a student development project around a tech startup called Northstar, a productivity-workspace. I designed a consistent navigation and visual style, then built separate pages for the product overview, company and project profile, workspace-record management, and sample-data analytics.

This is a front-end demonstration, not a connected Northstar product or production service. The records and analytics use illustrative sample data.

How it was built

Each page is written with semantic HTML and styled using responsive CSS. JavaScript powers the mobile navigation and CRUD form; browser local storage keeps demo records between visits. Chart.js renders the analytics visualizations.

  • HTML5
  • CSS3
  • JavaScript
  • Chart.js
  • Browser localStorage

What I learned

Building the project brings together page structure, responsive layouts, accessible navigation and form feedback, safe DOM rendering, persistent browser data, and data visualization. Separating the CRUD and analytics behavior into dedicated scripts also keeps each feature easier to maintain.
